# Учебный проект "Менеджер задач"

## Настройка
Необходимо создать и настроить файл .env по образцу .env.example

Нужно создать базу данных на postgres.
Для развертывания БД использовать sql-команды из файла migration.sql

## Запуск

Встроенный PHP веб-сервер необходимо запускать с указанием файла-роутера:

```shell
php -S 127.0.0.1:8000 rewrite.php
```
